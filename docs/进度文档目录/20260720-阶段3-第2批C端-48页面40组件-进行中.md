## 四、约束（公共要求）

1. uvue + uts（不是 vue + js）
2. 强类型：所有 type 必须显式声明
3. API 调用 import from `@/api/business/{module}.uts`
4. 组件 easycom 自动导入：`^love-(.*)` 等前缀映射
5. 风格严格参照 `frontend/app/pages/business/job/` 样板
6. 支持下拉刷新、上拉加载
7. 适配 H5 + 小程序 + App 三端
8. 单位用 rpx（不用 px）
9. 颜色用主题色变量
10. pages.json 注册每个页面
