### 5. Service 层（3 个文件）
- `service/rider.go`：Apply / Update / GetByID / GetByUserID / List / AdminList / Online / Offline / Audit / UpdateStatus / Earnings
- `service/delivery.go`：Create / GetByID / GetByDeliveryNo / List / ListByRider / AdminList / Grab / ArriveShop / Pickup / Deliver / Complete / Cancel / Stats
- `service/rider_settlement.go`：Generate / GetByID / List / ListByUser / Audit / Withdraw / Stats
- 业务规则已实现：
  - 骑手接单（Grab）：在线 + 信用分>50，更新 delivery.status=1，rider.online_status=2（含回滚）
  - 取货（Pickup）：更新 delivery.status=3，记录 picked_at
  - 送达（Complete）：更新 delivery.status=5，记录 delivered_at，rider.total_orders+1 + total_earnings += (delivery_fee + tip)，骑手回到在线状态
  - 结算生成（Generate）：net_amount = total_fee + total_tip - platform_fee，幂等（同周期更新）
