## 一、开发目标

依据用户规则"必须对标同类行业第一的功能，不要做一般的模块"，开发拼车出行模块（pinche）后端代码，按 ershou/car 样板标准。

### 关键差异化能力

1. **行程智能匹配**：route 表 + 起点终点+时间+座位+车主评分综合匹配
2. **顺风车保险**：每次行程自动投保（insurance 表）
3. **车主认证**：身份证+驾驶证+行驶证+车辆照片（driver 表）
4. **行程分享**：trip 表 share_token 字段
5. **紧急联系人**：emergency 表（一键报警 + 行程分享）
6. **ETC支付**：payment 表 payment_method=etc

## 三、技术规范

1. 主表 pinches 通过 GORM AutoMigrate 创建
2. 子表通过 SQL 迁移脚本创建（CREATE TABLE IF NOT EXISTS）
3. JSONB 字段不用 default:'[]'::jsonb，只用 type:jsonb
4. 所有表用 RegionBaseModel
5. 金额字段 decimal(12,2)
6. JSON 字段用 jsonb
7. 索引名遵循 PostgreSQL 默认命名
8. 迁移脚本全幂等
9. updated_at 触发器
10. 路由前缀 /api/v1/pinche，admin 子组使用 router.Group("/admin")
11. 错误码定义在 error_code.go 末尾（5101-5130）
