## 一、开发目标

依据 v3.2.1 架构方案与用户规则"必须对标同类行业第一的功能"，开发 linggong 零工兼职模块后端完整功能。

### 对标平台
- 斗米（任务制 + 长短期分类）
- 青团兼职（兼职合同电子化）
- 兼职猫（薪资日结 + T+0/T+1/T+7）
- 猪八戒（技能标签 + 雇主双向评价 + 信用分）

### 关键差异化能力
1. 任务制：按件/按时/按日计费 + 长短期分类
2. 薪资日结：T+0/T+1/T+7 多种结算方式
3. 雇主双向评价：工人评价雇主 + 雇主评价工人
4. 技能标签：技能认证 + 标签匹配
5. 信用分：履约/违约影响后续接单
6. 兼职合同电子化：在线签署电子合同
