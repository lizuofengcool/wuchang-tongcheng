# 【tenant 多租户分站中台模块开发】

- 开发人员：AI助手
- 创建时间：2026-07-21
- 当前状态：✅ 全部完成（后端 + 迁移脚本 + 管理后台 4 页面 + 路由注册 + go build 通过）

## 一、开发目标

依据架构设计文档 `docs/架构设计/ershou-大模块架构方案.md` 第 4.10 节多租户分站中台（tenant）设计，开发 tenant 多租户分站中台模块（全栈）。

- 模块名：tenant
- 中文名：分站中台
- 路由前缀：/api/v1/tenant
- 核心功能：无限城市分站/独立配置/独立域名/独立运营权限/配置一键复制/数据隔离

## 二、技术栈

- 后端：Go 1.25 + Gin + GORM + PostgreSQL 17.4
- 管理后台：Vue3.4 + Element Plus 3.0.0 + Vite5
- 数据库：wuchang_tongcheng

## 三、模块设计

### 3.1 表结构清单（4 张表）

| 序号 | 表名 | 说明 |
|------|------|------|
| 1 | tenant_stations | 分站主表（region_id 唯一） |
| 2 | tenant_staff | 分站员工（operator/manager） |
| 3 | tenant_configs | 分站配置（按模块+键） |
| 4 | tenant_domains | 域名绑定（domain 唯一，主域名+SSL） |

### 3.2 后端目录结构

```
backend/internal/modules/tenant/
├── model/          # 4 个 model 文件（station/staff/config/domain）
├── dto/            # 请求/响应 DTO（4 个文件）
├── repository/     # 数据访问层（4 个文件）
├── service/        # 业务逻辑层（4 个文件）
├── handler/        # HTTP 处理器（4 个 + common.go 辅助）
└── plugin.go       # 插件注册
```

### 3.3 管理后台页面（4 页面）

| 序号 | 路由 | 页面 |
|------|------|------|
| 1 | /settings-center/middleware/tenant/stations | 分站管理 |
| 2 | /settings-center/middleware/tenant/staff | 员工管理 |
| 3 | /settings-center/middleware/tenant/configs | 配置管理 |
| 4 | /settings-center/middleware/tenant/domains | 域名管理 |

## 四、约束

1. 严格遵循 dh114 样板（model/dto/repository/service/handler/plugin 分层）
2. 错误码段：5601-5630（在 plugin.go 中定义常量，不修改 error_code.go）
3. 权限码：`tenant:manage`（admin 路由）
4. 路由前缀：`/api/v1/tenant`（公开 + 需登录）+ `/api/v1/tenant/admin`（需 tenant:manage 权限）
5. 不修改 modules.go 和 error_code.go（由主进程统一处理）
6. 迁移脚本全幂等 + updated_at 触发器 + COMMENT 注释
7. JSONB 字段复用 dh114 风格
8. init() 调用 plugin.AutoRegister
