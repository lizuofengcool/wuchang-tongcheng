## 一、开发目标

为 wuchang-tongcheng 项目 pinche 拼车出行模块开发 C 端 12 页面 + 10 组件 + 1 API 文件，技术栈为 uni-app x（uvue + uts）。

### 关键能力对标
1. 行程列表/详情/发布/搜索（对标哈啰/嘀嗒）
2. 我的预订/行程记录（双视角）
3. 车主认证 + 车辆信息管理
4. 路线收藏 + 快速发布
5. 行程消息/聊天
6. 紧急联系 + 一键 SOS + 行程分享
7. 评价（评价表单 + 评价列表）

## 三、技术规范

1. uvue + uts（不是 vue + js），用 `<script setup lang="uts">`
2. 强类型：所有 type 显式声明
3. API 调用 import from `@/api/business/pinche.uts`
4. 组件 props 必须有显式类型定义
5. 单位用 rpx（参考 job 模块使用 px，保持一致）
6. 颜色用主题色 #FF6B35
7. 必须支持下拉刷新、上拉加载
8. 必须有空状态、加载状态、错误状态处理
9. 不能用 web API，用 uni.* API
10. 严格参照 job 模块代码风格
