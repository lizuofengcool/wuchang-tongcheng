## 四、约束（公共要求）

1. 所有表用 RegionBaseModel（含 region_id 地区隔离）
2. 金额字段 decimal(12,2)，不用 float
3. JSON 字段用 jsonb
4. 索引名遵循 PostgreSQL 默认命名
5. 字段类型严格对标头部平台（淘宝/京东/拼多多）
6. 注释完整
7. service 层暴露接口给其他模块调用
8. Plugin 接口实现 Name/Version/Meta/Init/RegisterRoutes/Close
9. 迁移脚本全幂等（DROP IF EXISTS + CREATE）
10. updated_at 触发器
11. 主表通过 GORM AutoMigrate 创建，子表通过 SQL 迁移脚本创建
12. JSONB 字段不能用 default:'[]'::jsonb
13. Gin 路由参数名一致性 + PostgreSQL 保留字用双引号

### 关键决策（依据 dh114 现有风格）

1. 表名前缀：`mall_`（如 mall_shops/mall_products/mall_skus...），主表 mall_shops 由 GORM AutoMigrate 创建，子表由 SQL 迁移脚本创建
2. 错误码段：5401-5430（dh114 用 5301-5330，pinche 用 5101，linggong 用 5201，mall 顺位 5401）
3. 权限码：`mall:audit`（M 端审核）+ `mall:read`（C 端浏览，公开免鉴权）
4. 路由前缀：`/api/v1/mall`（C 端）+ `/api/v1/mall/admin`（M 端，需 mall:audit 权限）
5. JSONB 类型复用 dh114 风格（自定义 JSONB 类型，实现 Valuer/Scanner）
6. 金额字段统一 `decimal(12,2)`（库存/价格/订单金额）
7. 路由参数名一致性：`:id` 表示主资源 ID，`:product_id`/`:order_id` 等表示子资源父 ID
