# DIY 前端页面中台模块开发

## 任务说明

为 wuchang-tongcheng 项目开发 diy 前端页面中台模块（全栈：后端 + 管理后台 + 迁移脚本），包括：
- 后端：4 子域（page/component/template/stat）完整分层（model/dto/repository/service/handler/plugin.go）
- 迁移脚本：4 张表 + 索引 + 触发器 + 注释，全幂等
- 管理后台：API 封装 + 4 个管理页面 + 路由注册

## 设计要点

### 4 张表设计
- `diy_pages`（RegionBaseModel，地区+用户隔离）：Title/Type/Slug/Status/UserID/BizID/PublishedAt/Components/Settings
- `diy_components`（BaseModel，全局共享）：Name/Code(unique)/Category/Description/Thumbnail/Status/Config
- `diy_templates`（BaseModel，全局共享）：Name/Thumbnail/Description/Category/Status/Pages
- `diy_page_stats`（BaseModel，按日期+page_id 汇总）：PageID/ViewCount/ClickCount/ConversionCount/StatDate（含 page_id+stat_date 唯一约束）

### 路由设计（30+ API）
- 公开路由：GET /pages/by-slug/:slug、GET /components/by-category/:category、POST /stats/{view,click,conversion}
- 需登录路由：GET /pages/mine、POST /pages、PUT/DELETE /pages/:id、POST /pages/:id/{publish,offline,copy}、POST /templates/:id/apply
- admin 路由（diy:manage）：GET /admin/pages、PUT /admin/pages/:id/status、组件/模板 CRUD、统计查询/汇总

### 错误码区间
- 6001-6030（14 个错误码，通过 utils.RegisterCode 在 plugin.go init() 注册，未修改 error_code.go）

- 设计限制：页面内容编辑（title/components/settings）通过 C 端 PUT /pages/:id 接口实现，该接口校验 p.UserID == operatorID。非创建者管理员无法直接编辑页面内容，只能通过 PUT /admin/pages/:id/status 管理状态。这是后端 service 层的设计选择，符合"管理员管理合规性、所有者管理内容"的分工原则。
