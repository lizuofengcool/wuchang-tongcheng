## 一、开发目标

为 wuchang-tongcheng 项目 news 同城头条模块开发 C 端 6 页面 + 6 组件 + 1 API 文件，技术栈为 uni-app x（uvue + uts）。

### 关键能力对标
1. 头条列表（分类 tabs + 搜索 + 卡片列表 + 下拉刷新）对标今日头条
2. 头条详情（内容 + 图片 + 点赞 + 收藏 + 评论列表 + 发表评论）
3. 搜索（搜索框 + 热门 + 历史 + 结果）
4. 发布头条（表单：标题/内容/分类/图片/地区）
5. 我的收藏（收藏列表 + 取消收藏）
6. 消息通知（消息列表 + 未读数 + 标记已读）

## 三、技术规范

1. uvue + uts（不是 vue + js），用 `<script setup lang="uts">`
2. 强类型：所有 type 显式声明，不用 any
3. API 调用 import from `@/api/business/news.uts`
4. 组件 props 必须有显式类型定义
5. 单位用 px（与 mall/job 模块保持一致）
6. 主题色 #FF6B35
7. 必须支持下拉刷新、上拉加载
8. 必须有空状态、加载状态、错误状态处理
9. 不能用 web API，用 uni.* API
10. 严格参照 mall 模块代码风格
11. 登录守卫：需登录操作使用 requireLogin()（auth.uts 已存在，语义等同 guardLogin）
